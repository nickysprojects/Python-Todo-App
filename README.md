# Python-Todo-App
Creation Date: April 19, 2026

Summary: A Python to-do app script that utilizes JSON to save the application state.

Features
* Enter & save tasks
* Delete tasks
* Rearrange tasks
* Complete and incomplete a task
* Customizable "task complete" icon
* Exit the program at any stage
* Load tasks / save state using JSON

Libraries
* JSON
* pathlib

  
Overview
This is actually the first actual program I've ever made. I attempted this after having just learned file reading, JSON, and OOP concepts.
Looking back, I can see a million things I would change about this program if I were to rewrite it today. However, I'm still very surprised and proud of how functional it is.
I decided to post this as it is so that one day I can hopefully look back on it and see how far I've come!
My organization, OOP skills, and overall understanding of programming have gotten far better since this program.
